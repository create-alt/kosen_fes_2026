# HYBRID OVERDRIVEの追加

Unityの操作は自動実行していません。以下のメニューをユーザー側で実行すると、現在の戦闘シーンに3体目と選択カードを追加します。

1. `SampleScene` など、既存の2体と選択画面があるシーンを開きます。
2. Playを停止し、スクリプトのコンパイル完了を待ちます。
3. メニューの **FightEngineering → Setup → Add Hybrid Overdrive** を実行します。
4. 選択画面に3枚のカードが並び、Hierarchyに `HybridOverdrive` が追加されます。シーンを保存してください。
5. 必要に応じてPlayやWindowsビルドで確認します。

既存の液体の敵を複製して、新しい攻撃制御を設定します。元の2体の攻撃設定は変更しません。操作はUndoで戻せます。登録済みの場合は重複して追加しません。

## 攻撃構成

| 残りHP | 攻撃 |
| --- | --- |
| 66%超 | 全幅の上段波と正面3連射を交互に使用 |
| 33%超～66% | 上段波と正面4連射を重ねて使用 |
| 33%以下 | 上段波を2回、正面5連射を組み合わせて使用 |
| 10%以下 | 既存のフィニッシュラッシュに移行 |

- 波は左右の移動範囲を覆います。頭を下げて避けます。
- 正面弾は発射ごとにプレイヤーの左右位置を狙い直します。高さに関係なく当たるため、左右移動で避けます。
- 後半は、頭を下げながら左右へ移動する複合回避が必要です。
- 近距離では下段を広く覆うパンチも使います。下側の予測帯を見て、後ろに下がって避けます。
- パンチは波・正面連射とは独立して動きます。パンチの予告中や動作中にも波や連射が発生します。
- 予測表示は既存と同じで、波は横線、正面弾は縦線です。発射後の追尾はありません。
- 正面弾は連射時も1発ずつ狙いと予測表示を更新します。敵の被弾では中断しません。
- 撃破・プレイヤー死亡・ラッシュ・メニュー復帰では攻撃を停止します。

紫のボディと金色のアクセント、冠状のパーツで通常の液体の敵と区別します。波には既存の両腕モーション、正面連射には右腕、近距離パンチには左腕のモーションを使います。重なる場合は左腕のパンチを優先し、波と連射の攻撃処理は継続します。

敵HPとPlayer HPは既存の選択画面で設定します。プレイヤーの攻撃ダメージは固定のままです。液体の敵と同じ連打ガードも継承します。難易度設定で予告や速度は変わりますが、この敵は最低3連射の高難易度コンテンツです。

## 手動で構成する場合

液体の敵を複製し、`DilatantEnemy` と `DilatantLiquidAttack` があるオブジェクトへ `HybridBossAttack` を追加します。`Player` とPunchBotと同じ `Missile Prefab` を設定します。`DilatantLiquidAttack` は外部制御で動きます。

さらに `EnemySelectionController` のEnemy Choicesと、`FightGameUI` のEnemy Cards・Enemy Faces・Selected Marksに3体目を登録する必要があります。通常は追加メニューを使用してください。

コンパイル確認と実機確認は別です。シーンへの追加操作、Play、ビルド、回避難易度の実機確認は実施していません。
