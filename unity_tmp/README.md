# FightEngineering

画像処理で検出した前後移動・頭の高さ・パンチを使って遊ぶ、Unity製のボクシングゲームです。画像処理PCが操作データをUDPで送り、ゲームを動かすPCが受信します。画像処理PCがなくてもキーボードで試せます。

## 起動方法

1. Unity Hubでプロジェクトフォルダーを開きます。使用バージョンは **Unity 6（6000.0.32f1）** です。
2. [SampleScene](Assets/Scenes/SampleScene.unity) を開き、Playを押します。エディターのGameビューで敵選択画面が見えない場合は、**Display 1** を選びます。
3. PunchBotまたはDilatant Sentinelを選び、難易度、両者の最大HP（10〜1000）、音量を設定して対戦を開始します。

敵の体力が残りわずかになると、フィニッシュラッシュが始まります。敵の攻撃が止まっている間に、5秒以内に8回パンチするとK.O.です。時間切れになると通常の対戦に戻ります。

## キーボード操作

敵選択画面で「キーボードでテスト」をオンにします。

| キー | 操作 |
| --- | --- |
| W / S | 前進 / 後退 |
| ↑ / ↓ | 体全体を上げる / 下げる |
| U / J | 頭の位置を上げる / 下げる（Jでしゃがむ） |
| I / K | 足元の位置を上げる / 下げる |
| Space | パンチ |
| Home | 位置と姿勢を初期状態に戻す |
| R | 対戦をやり直す |

## 画像処理PCとの接続

UnityをPlayにしてから、画像処理側で **UDPポート `5005`** に送信します。別PCから送る場合は、Unity側のPCで `ipconfig` を実行し、使用中のネットワークアダプターのIPv4アドレスを送信先に指定してください。同じPCから送る場合は `127.0.0.1` を使います。ポートは、UnityのPlayerオブジェクトにある Player Controller の **Tracking Udp Port** で変更できます。

1パケットに1件のJSONをUTF-8で送信します。

```json
{"forward": 0.5, "head": 0.667, "feet": 0.0, "punch": 0}
```

| 項目 | 値 |
| --- | --- |
| `forward` | `0〜1`。最も後ろが `0`、初期位置が `0.5`、敵の手前が `1`。 |
| `head` | `0〜1`。足元の高さが `0`、上昇上限が `1`。直立姿勢の目安は `0.667`。 |
| `feet` | `0` を送ります。ゲーム内では常に `0` として扱います。 |
| `punch` | 数値の `0` または `1`。`0→1` でパンチ1回です。連打の間には `0` を送ります。 |

パンチがないときもデータを継続して送ってください。キーボードテストがオンでも、有効なUDPデータが届いている間はUDP入力が優先されます。約0.5秒届かなければ、キーボード操作に戻ります。

### 受信テスト

UnityをPlayにし、相手PCのターミナルで次を実行します。`UNITY_PC_IP` はUnity側のPCのIPv4アドレスに置き換えてください。Python 3を使います。

```sh
python -c "import socket,json; s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM); s.sendto(json.dumps(dict(forward=0.5,head=0.667,feet=0,punch=0)).encode('utf-8'),('UNITY_PC_IP',5005))"
```

UnityのConsoleに `[UDP受信]` と送信元が表示されれば、通信できています。対戦開始前でも確認できます。上のコマンドは1回だけ送るので、ゲーム操作の確認には継続送信を使ってください。

ログが出ない場合は、送信先IPとポート、UnityがPlay中か、WindowsファイアウォールでUDP `5005` の受信が許可されているかを確認します。別の受信ツールを同じポートで使うときは、UnityのPlayを止めてから起動してください。
